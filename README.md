I build tools I wanted and couldn't find, and then find out why nobody built them. Lately that means agent plumbing, developer tooling, and running models on the laptop in front of me.

> [!NOTE]
> **The recurring bug in my personality:** I can't use an abstraction for long without rebuilding it. The state library, the web framework, the inference path, the agent loop. I'm not against abstractions. I just like knowing what they're abstracting.
